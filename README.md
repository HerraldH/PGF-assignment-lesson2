# PGF-assignment-lesson2
Maak nu zelf een game.

• Het hoeft geen “dungeon game” te zijn, Je mag ook door een stad lopen 
en winkels in gaan, of met de auto van je werk naar huis rijden

• Er moeten (minimaal) 3 lagen in zitten, dus er zijn 2 if-statements tot 
het eind.

• Zorg dat je de input valideert

• Teken eerst je idee uit (op draw.io of op papier)

• Denk ook na over welke tekst je wilt printen, welk verhaal je wilt 
vertellen
